# 术语对照表（中英）

> 本 skill 中英术语混用；英文原词保留以便对照西方剧作理论原著。

| 中文 | 英文 | 含义 |
|------|------|------|
| 前提 | Premise | 故事要用戏剧动作证明的命题，含人物倾向+冲突+结局方向 |
| 控制理念 | Controlling Idea | 由高潮表达、带价值判断的故事意义 |
| 道德前提 | Moral Premise | `[美德]→[正面]，[恶行]→[负面]` 的正反证明结构 |
| 设计原则 | Designing Principle | 故事的独特组织逻辑（常用于文学小说替代常规情节机制） |
| 节拍 | Beat | 最小叙事单位，一次动作—反应交换使价值发生位移 |
| 场景 | Scene | 一个或多个节拍，使价值由正转负或反之；不转折就不是场景 |
| 序列 | Sequence | 2–5 个场景，构建到一次中等逆转，自成小弧 |
| 幕 | Act | 若干序列构建到改变故事方向的重大逆转 |
| 转折点 | Turning Point | 价值发生位移的时刻 |
| 缺口 | Gap | 期望与结果之间的落差，一切戏剧张力的来源 |
| 渐进复杂化 | Progressive Complication | 每个缺口更宽、赌注更高、行动更绝望的过程 |
| 激励事件 | Inciting Incident | 打破日常平衡、启动故事的事件 |
| 危机 | Crisis | 高潮前的终极抉择时刻 |
| 高潮 | Climax | 人物面对转变终极考验的对峙 |
| 人物塑造 | Characterization | 可观察的表层（举止、语言、外貌） |
| 真性格 | True Character | 只在压力下、真正有得失时显现的选择 |
| 三维 | Three Dimensions (Egri) | 生理 / 社会 / 心理 |
| 心理需求 | Psychological Need | 人物必须学到的关于自身的认识（内在） |
| 道德需求 | Moral Need | 人物如何伤害他人或自己且不自知（外在） |
| 创伤 | Wound | 需求的起源经历，解释人物为何抗拒改变 |
| 弧光 | Character Arc | 人物在压力下的转变轨迹（正/负/平） |
| 对手 | Antagonist | 承载道德前提另一面、拥有自己合理目标的对抗者 |
| 对抗网络 | Web of Antagonism (Truby) | 多个人物从不同角度反对主角的结构 |
| 平弧 | Flat / Testing Arc | 人物已知真理，故事考验其能否守住 |
| 冰山原则 | Iceberg Theory (Hemingway) | 作者知道全部，纸上只露八分之一 |
| 否定之否定 | Negation of the Negation (McKee) | 最坏结果戴着最好结果的面具 |
| 自由间接引语 | Free Indirect Discourse | 用人物声音承载叙述与说明 |
| 类型梗 | Trope / 梗 | 题材中的标准桥段，可保留、反转或替换 |
| 反俗套 | Anti-cliché | 主动识别并偏离题材陈词滥调 |
| 去 AI 味 | De-AI / Deslop | 清除 AI 高频词、模式与腔调的修订流程 |
