# 人物工坊

> 两档深度，按需取用。**不要默认让用户填问卷**——先给轻量卡，用户要深入再展开。
> 理论基础见 `methodology-overview.md` §2（人物架构）。

## 轻量人物卡（默认）

只问 6 项，够支撑大多数故事：

```markdown
👤 [人物名]
- 欲望（明面上想要什么）：
- 需求（真正需要学会/面对什么）：
- 创伤（是什么造就了现在的他）：
- 核心矛盾（内在自相矛盾之处）：
- 弧线方向：正向转变 / 负向堕落 / 平弧考验
- 与主角的关系：盟友 / 对手 / 镜像 / 考验者
```

**判断标准**：填不出"需求"或"核心矛盾"的人物，通常是功能冗余的，考虑合并或删除。

## 深度人物架构（按需）

在轻量卡基础上展开：

### Egri 三维
- **生理**：外貌、健康、能力——世界看到的部分。
- **社会**：阶级、教育、职业、关系、社群位置。
- **心理**：驱力、恐惧、矛盾、道德倾向、智力、气质。
> 三者足够深时，人物在压力下的行动变得**必然**，情节从人物生长。

### 三层标签对比法（用于快速定声音与反差）
- **表层标签**：一眼可见（职业、外貌）。
- **深层标签**：读下去才看出（隐藏动机、内心创伤）。
- **反差标签**：与深层矛盾的行为（越懦弱的人关键时刻越可能站出来）。

### 对手设计
- 对手是**自己故事里的英雄**。
- 承载道德前提的另一面，与主角追求同一或直接竞争的目标。
- 最强的对手**在某个点上是对的**——拥有主角必须正视的合理视角。
- **对抗网络**：多人物以不同方式反对主角，比单一反派更丰富。

### 反派层级（网文向）
| 层级 | 跨度 | 要求 |
|------|------|------|
| 单元反派 | 1–5 章 | 快速建立、快速解决 |
| 篇章反派 | 10–30 章 | 有一定深度，服务当前篇章 |
| 大篇章反派 | 贯穿多线 | 与主线目标持续冲突 |
| 终极反派 | 全书 | 与主角形成镜像对立，承载主题反面 |

## 人物关系网与秘密

让人物之间存在误解、遮掩、错位，而非平铺关系：

```markdown
【关系张力】
- A 与 B：依赖 / 误解 / 信息优势 / 情感错位

【秘密分布】
- 人物：
  - 秘密：
  - 一旦暴露会怎样：

【错位认知】
- 事件：
  - 人物A怎么理解：
  - 人物B怎么理解：
```

## 散文专属提醒
- 内心视角（思想、记忆、感觉）**仅当与外部行动矛盾或使其复杂化时**才最有力量。
- 别用内心视角替代戏剧动作——无后果的思考不是故事。
- 让人物自己暴露自己，不要作者旁白总结。
